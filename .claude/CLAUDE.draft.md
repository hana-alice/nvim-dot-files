# Workflow Protocol

MANDATORY for every task. Overrides default behavior.

## 1. 起止标记

- 工作**开始前**：回复第一行输出 `🚀 <一句话说明>`
- 工作**结束后**：回复最后一行输出 `✅ <一句话总结>`（阻塞用 `⛔`，失败用 `❌`）
- 纯对话答疑不强制。

## 2. Progress 进度文件

每段工作都在**当前项目根目录**的 `.claude/` 下维护按日期命名的进度文件
（永远跟着项目走，绝不放全局 `~/.claude/`；文件夹不存在就先建）：

```
<项目根>/.claude/<YYYY-MM-DD>-progress.md
```

**每次开工前先更新它再动手。** 必含区块：

```markdown
# Progress — <YYYY-MM-DD>

## 总目标
<最终目标，跨天延续，不重写>

## 已完成
- [x] <项 + 验证状态>

## 未完成
- [ ] <项>

## 当前任务
<此刻在做的唯一一件事>

## 备注
<风险 / 阻塞 / 决策 / 坑>
```

完成一项就从「未完成」移到「已完成」。保持精炼，别堆日志。

## 3. 执行顺序

开始标记 → 更新 progress → 执行 → 回写 progress → 结束标记
