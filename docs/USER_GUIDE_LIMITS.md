# 使用边界与验证说明

操作路径见 [使用手册](USER_GUIDE.md)。本文集中记录保留范围、预算、外部前提和验证含义；
成功提示只按对应动作的证据解释，不能替代尚未完成的工程或设备验收。

## 首次使用与目标选择

工作台的打开和刷新只查看已有状态，不启动构建、设备检查或索引。
首次上手向导由用户明确发起，逐项补齐工程、平台/配置及该目标需要的设备/包名，
Prepare 单独确认；取消会结束流程，迟到回调不得继续启动任务。
已经确认且开始执行的 Prepare 沿用原任务生命周期，可从任务面板停止；取消向导不会重放它。
向导完成不等于首次 `gd` 成功，也不证明设备在线、符号匹配或全工程索引已经完成。
这些分别由索引状态、环境检查、调试预检和真实导航验证。

Android 设备是当前 Neovim 进程的选择，不影响另一个实例，重启后需重新选择。
工程、平台、包名会记住。当前目标中的设备和包名只是选择信息，在线与调试就绪另行核实。
命令中枢的能力检查不等于索引覆盖；需要按提示配置，再明确确认继续原动作。

## 工作台与构建结果

构建读取磁盘，不自动保存文件。工作台只显示当前工程的构建记录；切换工程后需切回查看原记录。
每条记录固定自己的运行编号、目标、错误和输出；搜索或选择变化不会把旧证据转给新目标。
“该次进程退出 0”只表示那次构建进程成功退出，不代表之后的修改、部署、测试或索引通过。
历史记录不能完整重放原配置，“构建当前目标”始终使用当前选择。

构建记录属于当前 Neovim 实例，最多保留 16 次已结束构建，不跨重启。
错误快照超出预算时标“部分记录”；输出已删除或证据不可用时说明原因，不打开无关当前结果。
此入口覆盖已有终端构建，分布式构建、Editor 测试和其它工作流结果仍由各自入口查看。
同一标签页重复打开复用一个工作台；关闭工作台不停止后台任务。
后台任务回车只查看输出或详情，停止需明确操作。

## 恢复入口与保留范围

统一恢复菜单只调用原有入口，不改变各自的保留范围：

| 内容 | 范围与限制 |
|---|---|
| 最近构建错误/日志 | 上一节的本实例构建凭据；无有效记录时不能借最新日志冒充 |
| 窗口、隐藏文件、结果、任务、日志 | 当前原生窗口、缓冲区、quickfix 历史和任务句柄；内容仍在才可打开 |
| 具名调查 | 持久文件位置、完整搜索条件与下一步；原实例结果引用单独处理 |
| 会话 | 文件名与布局；不代替未保存文本快照 |
| 异常文本 | 下文有界快照；恢复到新缓冲区，不覆盖原文件 |

关闭文件或输出窗口不会停止任务、重新运行任务或丢弃未保存内容。
缓冲区已删除、日志已淘汰、窗口内容已改变时明确告知；过期条目可刷新。
Workspace 的 Ctrl-O 只处理仍隐藏的普通文件；日志、终端、任务和结果用回车。
文件已显示时回车聚焦已有窗口；普通隐藏文件回车保留新分屏恢复方式。
窗口固定了文件，或文件设置为隐藏时删除/卸载时，界面会说明原因并保留当前内容。
打开列表后改变来源窗口或文本时，应从所需编辑区重新打开列表。
Ctrl-X 只停止选中的已登记后台任务；DAP 停止仍走专用调试停止，不纳入通用取消。

构建输出、原生 quickfix、logcat、任务共用每标签页一个底部窗口。
切换不叠窗口或停止任务，构建结束后的输出仍可回看；阶段历史最多保留 16 份。
后台输出和失败结果保留编辑焦点，主动打开才进入面板。
面板切换本身不启动设备命令；没有日志读取任务时需先打开应用或调试日志入口。

## 运行循环与部署

每次循环固定发起时的工程、配置、设备和包名，过程中切换只影响下一次。
任何阶段失败立即停下；最后成功以应用启动或调试附加回应为准，发出请求不等于成功。
每次仍进入构建检查，部署确认 SO 的 SHA-256 未变时显示复用；尚未启用前端跳过 UBT。
命名运行配置保存平台、编译配置、包名与运行方式，不保存设备 serial。
空闲时的 F5 服从运行方式，会话中的 F5 仍是 continue。

SO 热替换要求已安装 APK 有同一套 Java/JNI 基线；改了引擎版本或 Java 层，需先安装匹配 APK。
安装与 SO 部署不自动启动应用，启动使用显式运行入口。
构建问题列表将 error 放在 warning 前，warning 和其它输出仍保留；没有源码位置的失败另行提示。
搜索或崩溃分析也会替换当前 quickfix，继续处理某次构建时先从它的记录找回错误。
quickfix 导航到边界会提示，不自动改用另一个列表；打开侧栏不会改变 quickfix 导航目标。

## 调试

调试 UI 保留原源码分屏；停止时恢复未被主动改变的阅读位置与比例。
调试期间新建、关闭、调整分屏或编辑文件会保留新选择；只清理本次调试拥有的窗口。
重新附加沿用上次成功会话的设备、包名和符号，不能替代新的匹配检查。

应用有 PID 却长期附加不完成，可能是 Android 后台实例冻结；这是所选设备已实测的情形，
不能仅凭 PID 或通用错误推广到所有设备。可先正常启动置前台，再附加，无需关闭系统冻结策略。
UE 名称、字符串和复杂类型的显示与同构建真机验证仍有范围限制，不能从 UI 非空推定全部可读。
工具链、连接、系统权限、调试引擎、符号分别按失败层的 evidence 判定，未判定时不猜层。

## 日志与崩溃

向上阅读会暂停跟随，新日志不会拉回底部。切换级别、筛选、隐藏或停止读取后仍能回看已收集内容。
历史最多 12000 行或 8 MiB，淘汰或单行截断时有提示。
崩溃帧不能对应符号时原样保留并标 `[unresolved]`，不伪造源码位置。
符号库按构建 ID 匹配，与调试器共用；无匹配库表示设备包与本机当前构建无法证明同一次构建。

## 语义导航与连续阅读

C++ 定义由编译器语义决定；索引未准备好时诚实失败，不猜目标。
调用与类型层级需要当前 C++ 文件的 clangd 就绪，调用结果即使只有一项也先显示列表。
文件编辑后旧大纲不跳到过期位置，需重新获取；顶部上下文最多三行，高度不足 20 行不显示。
上下文仅辅助阅读，宏展开类/函数仍以符号大纲和编译器导航为准。

Peek 只有一个目标也保留预览；Ctrl-Q 保存后继续保留调查面板。
读取期间切文件、窗口或编辑，迟到结果会失效，不能替换新窗口内容。
阅读返回只在原布局/工程仍适用时恢复，不强行改回主动变更的工作现场。
关系树按展开查询；循环、范围限制与失败可见，“覆盖未知”不能用来断言没有调用者或派生类。
验证记录见 [搜索与导航验收](search-navigation-validation.md)。

## 行列与文件位置

行列从 1 开始，列是 UTF-8 字节列；多字节字符必须指向起始字节，空行只接受列 1。
越界或格式无效时拒绝，不夹到其它位置。未命名/未保存文档也可跳转。
等待期间编辑、改名或移动到其它位置会使旧跳转失效，需重新发起。
相对路径基于当前窗口工作目录，文件在目录外则保留绝对路径；空格路径会加引号。
复制不保存文件、移动光标或修改命名寄存器；未命名文件无可分享路径，保留原剪贴板并提示。

## 文件与工程搜索

工作区全文件与代码文件列表首次扫描后用当前会话快照，F5 刷新新增/删除文件。
冷/热列表范围一致；全文件含文档、脚本、配置和项目文件，代码入口仍只列代码。
超预算仍显示完整扫描结果并说明未缓存。工程/模块文件列表不用这份快照，变化后重新打开。

默认工程内容搜索只搜已索引文件；范围选择也只在已索引集合内生效。
缺索引会提示准备，不自动改用 rg；未索引内容需显式 rg 入口。
包含/排除参数不经 shell，glob 不应加 shell 引号。
标题明确等待、搜索中、无结果、错误或部分结果；截断、超时、取消不能标成完整搜索。
候选筛选默认不区分大小写，内容大小写模式独立；Ctrl-G 来回切换保留原内容查询。
正则无可靠列位置时标“行定位”，复制位置仅含路径与行，不虚构列。

## 当前文档查找

查找包含未保存/未命名文本，不为搜索保存文件；同一行多次命中分别列出。
确认在来源编辑区定位，分屏、标签与保存结果使用文件/工程搜索入口。
正则是 rg 的单行 Rust 表达式，非 Vim 替换语法；零长度匹配明确不支持，多行选区需缩到一行。
来源编辑后旧位置失效，F5 重读；主动移动光标或换窗口后需从目标文档重新打开。
大于 2 MiB 的文档提示限制；结果/输出超预算标部分，数量不能当全文总数。

## 搜索历史与结果

搜索历史按工程隔离；真正打开过结果的记录优先，带次数与时间。
新记录保留查询、来源、范围、大小写、整词、正则和文件筛选，工程身份不符时拒绝重放。
旧记录标 `legacy: query only; modes unknown`，不能还原未知模式。
最近内容搜索依据真实来源，不因最近来自 rg 而跳到更早的 csearch。

文件/内容搜索 Ctrl-Q 保存后回编辑窗口，不自动打开问题面板；阅读调查则保留调查。
最多保存 5000 行、8 MiB，原生历史保留 10 个列表；会淘汰当前结果时拒绝保存，需先明确换列表。
窗口关了可找回仍保留的结果，历史被淘汰需重新搜索。保存结果不等于具名调查的持久元数据。

## 重构与类生成

预览期间的新输入、文件或工程变化会使旧修改失效；不自动保存，应继续审阅并编译。
code action 只展示当前服务器实际提供的能力，无法预览的命令另行询问，不伪装成可预览修改。
整批撤销不覆盖后续输入；应用/撤销失败保留可检查的恢复记录。
UE 类/结构片段需填模块 API，generated header 放最后一个 include。
类生成只在现有项目模块预览创建，不修改 Build.cs 或创建缺失目录，仍需工程 UHT 与编译。

## 替换与诊断

Visual 替换作用于本次选区覆盖的行，同一行选区外相同文字也参与确认；按字面查找。
当前文件替换不自动保存。GrugFar 是独立多文件磁盘工具，遵循自己的筛选和写入流程，
不包含本仓重构预览和整批回退保护。

诊断列表只展示语言服务已提供的诊断，空列表不表示全工程编译通过。
全部/当前文件入口共用一个 Trouble 视图，重复执行会关闭；诊断独立于构建/搜索/崩溃 quickfix。
语言服务能力决定参数提示与修复可用性；普通撤销历史与整批重构回退是不同动作。

## Editor 测试

发现与运行会启动命令行 Editor。当前 Windows 入口要求所选引擎已有 Editor 可执行文件与工程模块，
不自动编译或安装。失败有日志与可取得的源码位置，不完整报告不能标成通过。

## 具名调查

默认关联当前标签页可见普通文件及位置、本工程完整搜索条件；其它文件/条件需明确关联。
按工程持久保存位置、条件和下一步，不含未保存文本；文件变更后的旧行列只是历史位置。
原实例构建结果、日志和进程不跨重启复活，不可用时说明，不借最新结果冒充。
调查不还原 target，不自动运行搜索、构建或索引；重新搜索是明确独立动作。
每工程最多 16 调查，每调查最多 32 文件；满额需明确管理，删除只移除记录，不删除文件或停止任务。
继续调查保留另一项工作的脏文件，只打开选中的文件，其余按需打开。

## 文件操作与关闭

改名/移动不覆盖目标，跨磁盘移动需另行处理；只改大小写先用未占用临时名。
操作前检查相关脏文件与已打开子文件；提示期间编辑、切目录或关树取消未开始动作。
语言服务器要求连带改引用/导入时，本入口无法预览就保留文件，符号重命名走重构预览。
改名后撤销历史仍可用。删除冻结旧文本保留为未命名脏文件，新编辑/重新保存的版本不被旧操作接管。
回收失败或事后检查发现变化，会提示保留/恢复路径，不表示自动回滚；先检查原位置的新内容，
再人工移回或另存；系统回收站恢复后仍需核对位置。
确认放弃后出现新编辑需重新检查，卸载回调的新文本保留为未命名缓冲区，可找回另存。
验证记录见 [日常安全验收](ide-daily-safety-validation.md)。

## 编辑格式化与退出

Alt-J/K 越界保持位置和模式，合法移动一次撤销包含缩进。
语法选择需要 Tree-sitter parser；picker 的 Ctrl-Space 是多选，不是文档语法选区。
C/C++ 向父目录查 `.clang-format` / `_clang-format`；无配置时跳过并允许明确选 UE 模板或取消，
不默认 LLVM 风格、不替工程创建配置。UE 模板是本仓配置，不是 Epic 官方配置。
选区可能扩到语法单元，块选区不支持，可用原生撤销。自动格式化默认关闭。
内联提示有原有超大文件保护；当前缓冲区可显式关闭。

退出集中处理全部未保存缓冲区。放弃再次确认，回车默认取消；新编辑、新文件或改名会取消旧退出。
直接选择文件也取消退出。未命名、只读、不可写或特殊缓冲区阻止保存后退出，原内容保留。
原生 q/qa 仍逐文件确认，qa! 是明确放弃；Restart 先检查未保存，取消不创建新实例。
验证记录见 [日常编辑验收](daily-edit-validation.md)。

## 会话与异常文本

按需会话恢复默认只加载当前文件，full 才完整恢复，可能启动更多解析；有未保存内容需先处理。
自动恢复保护为 24 文件、最多一个新增标签页；按需检查最多 256 项、1 MiB。
会话保存布局，不替代文本快照。

异常文本恢复到新的未命名缓冲区，保留原文件和已打开的新内容。
普通编辑约 1.5 秒合并落盘；每份最多 2 MiB，每进程 session 最多 64 个 buffer，
已退出旧实例按七天策略清理，超限/写入失败显示“恢复缓存未更新”。
默认只扫描当前工程，排除正常退出与仍运行实例，历史按最近 session 优先。
每轮最多 128 份快照、每目录 256 项，超限显示“扫描受限”，原快照保留。
最后尚未落盘的编辑和物理断电耐久性未保证。

## 状态栏与维护诊断

构建与循环片段表示最近那次动作；索引排队、Prepare 运行与索引完成是不同状态。
“可恢复文本”是启动扫描发现的快照；“恢复缓存未更新”表示某份写入失败。
维护诊断是维护者证据，普通使用可忽略。查看探针只标记已读，不代表已解决。
默认仅状态栏摘要，维护者可用
`require("ue.config").setup({ probe = { startup_notice = "notify" } })` 切回 INFO 通知；
默认值 `"statusline"`。未读证据依 report-first 每会话提示，不提供静默关闭。

全工程索引性能、可靠跳过 UBT 的输入证明、复杂 UE 类型的完整真机显示、Blueprint / Editor 资产关联，
仍需各自的工程/设备/Editor 验证；不能从局部回归或向导完成推出全部恢复。
SuperUnity 性能现状见 [索引调查](cpp-index-restart-investigation.md)。
