## 3. 本次工作归档

### 2026-10-04 — 保护日常文件操作并让常用动作可发现

**Task**

继续产品体验改进：优先处理文件和缓冲区的数据保护，将窗口找回、搜索、阅读与日常编辑完整写入操作手册。

**Implemented**

- 同一关闭 owner 覆盖 `bc`、`bd`、全部/其它缓冲区及 picker 删除，保护确认、保存、窗口交接与卸载期间的新文本，保留运行中的终端任务。
- 文件树统一改名/移动/删除，保护脏文档、已加载子文件和目标身份；宿主原子拒绝覆盖，隔离后异步回收，保持已打开文本。
- 活跃片段优先切字段；当前文件大纲沿用原生树，绑定版本、实际请求 ID、刷新和最终确认。
- 命令中枢补齐真实导航/搜索/历史入口与命令名显示，保护来源与目标，按实际关系提供者约束展示可用性。
- 操作手册增加任务索引和完整步骤，修正窗口关闭键、文件列表范围、F5 与恢复边界；同步架构、知识库、回归映射及两份主规格。

**Pitfalls / Gotchas**

- Noice 已有自动参数签名；Blink 的开关不能单独证明编辑器缺少该能力。保留现有唯一 owner。
- 确认、卸载与文件命名事件都可能产生新输入，不能只在弹框前核验；回收完成也不能接管后来重新保存的文档。
- 目标 stat 不能替代原子排他；异步回收不直接消费可重建的原路径，失败后保留对象并给出恢复位置。
- 关系菜单的可用性必须与实际 chooser 一致，不把任意方法广告当作 clangd 关系能力。
- 改名后的普通保存需刷新原生文件状态并保留 undo；内部临时呈现使用局部 noautocmd，真实命名/保存事件保留。隐藏 buffer 引用与原始文件名 magic 需单独保护，临时事件守卫及 picker auto_close hook 已删除。
- 定时器分配失败必须恰好一次拒绝并清理请求；受控失败注入不等同于真实 OOM。
