## 3. 本次工作归档

### 2026-10-05 — 当前文档行列直达与位置分享

**Task**

继续对标 IDE 的日常操作，直接按已知行列定位，并从当前编辑区复制可重新打开的文件位置。

**Implemented**

- `document_location.resolve/open` 严格解析当前内存文档行列，原生返回历史和输入期间来源保护；`<leader>fl` 直接进入。
- `document_location.copy` 复用文件列表的位置格式；`fy` 相对当前窗口目录、`fA` 绝对路径、`fY` 文件行列；不保存文本。
- Hub、操作手册、两份速查、回归映射和知识库同步；无新依赖，不更改文件列表既有宽松解析。

**Pitfalls / Gotchas**

- 文件列表的 parser 接受文件路径并会 clamp 零坐标；裸行列必须独立严格校验，UTF-8 字节列不能落在字符内部。
- 相对路径以当前窗口工作目录为根，不把项目启动默认值作为当前目录；取消和迟到确认不能改变新的编辑意图。
- 通用输入的 expr 回车会在快速同包输入时读取旧文字；改为非 expr 后，立即 stopinsert/关闭又会让来源退列。该能力复用 Snacks.win，自己在普通模式后关闭，不使用通用输入的强制 parent 回拉。
- 未命名寄存器可能指向用户命名寄存器，直接写 alias 会覆盖原文本；复制使用原生 yank 槽并显式更新 alias，命名寄存器保留。
