### 2026-10-05 — 当前开发工作台与按运行归属的结果

**Task**

让用户从当前目标发起构建，失败后搜索代码，再回到同一次错误和输出继续修复与验证。

**Implemented**
- `UEWorkbench` / `<leader>uH`：右侧工作台并排显示当前选择、下一步、工程构建记录和后台任务。
- 终端构建固定运行身份、退出凭据、错误快照和日志引用；列表按发起顺序保留，不把历史成功称为当前代码通过。

- 真正的 Windows 终端编译验收发现 ConPTY 标题控制序列插入源码路径；删除 OSC 后再解析，保留原文件、行列与诊断内容。
