# lua/nio/ — async 日志

> 继承 `../CLAUDE.md`（lua 总规则）。只写增量。

## 用途

轻量 async logger（`logger.lua`），供需要非阻塞日志的子系统使用。

## 专属约定

- **async 优先于阻塞**：本目录存在的全部理由就是不阻塞主线程。→ C4.2 / P6
- 保持单一职责、小依赖面；不要膨胀成通用框架。
- 公共 API 挂 `M.*`，可 headless 验证。
